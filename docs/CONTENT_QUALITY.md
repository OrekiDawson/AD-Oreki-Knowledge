# 知识库内容质量标准

**完整、正式且唯一的现行规则现已公开在网站根目录：**

- [反物质维度MOD Wiki:知识库规则](https://wiki.oreki.net/wiki-rules)
- [GitHub 中的正式规则源文件](https://github.com/OrekiDawson/AD-Oreki-Knowledge/blob/main/content/wiki-rules.md)

这份兼容入口用于保持旧的 `docs/CONTENT_QUALITY.md` 链接有效，避免同一套规则在两处维护并发生漂移。历史版本仍可通过此文件的 Git 记录查看。任何对编写规则的更改，均以 `content/wiki-rules.md` 为对象提交 PR。

关键约定：**简体中文、客观准确、通俗易懂、逐项可查证；正式页面名称统一为 `反物质维度MOD Wiki:[条目名]`；每篇正文末尾只保留一小块供 AI 检索的摘要。**
