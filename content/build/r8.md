# R8 分层策略

## 原则

- Debug：默认不混淆。
- Release：R8 OFF 为正式稳定路线；R8 ON 是受控实验，必须通过完整游戏、ABI、存档、挑战、
  阶段、GUI 与性能验证后才能进入正式门禁。
- 不用 APK 体积缩减宣称性能提升。

## 兼容入口保护

Smali 到 Kotlin 的 ABI、反射（含 GameApi）、Gson/Player 存档字段、Coroutine/Continuation、
Manifest 组件、JNI、资源 ID 等必须显式 Keep；先保守基线，再按真实回归收紧。

## 证据

状态：R8 OFF 已验证；R8 ON 实验
证据等级：实测 + 读码
适用版本：AGP 9.5.1
