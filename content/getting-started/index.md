## 阅读顺序建议

1. 先读游戏总览，建立对原版玩法层级的直观认识。
2. 再读项目概览，弄清楚 Android、Web、统一管理与知识库四个仓库的分工。
3. 按需要进入「玩法机制」「架构与运行时」「构建与交付」等专题分类。
4. 任何结论都回到正文中的 GitHub 原始链接核对；本站是阅读层，不是权威事实源。
